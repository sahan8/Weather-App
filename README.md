# Weather App

A simple Express + EJS app: type a city and it shows the current weather and temperature, using a weather API on RapidAPI.

![Weather App](screenshots/home.webp)

## Tech stack

- Node.js, Express
- EJS with express-ejs-layouts
- Axios

## Run it locally

```bash
npm install
npm run dev
```

Open <http://localhost:4000>, enter a city and click **Search**.

`npm run dev` uses nodemon; run `node app.js` if you don't have it installed.
